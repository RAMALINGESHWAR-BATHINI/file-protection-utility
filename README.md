# file-protection-utility
Python utility for encrypting and decrypting file contents securely.

## Overview
This project is a Python-based utility used to protect file content through encryption and restore it using decryption.

The program converts readable text into a secure encrypted format and allows recovery when needed.


## Features
- File encryption
- File decryption
- Data protection
- Secure key usage


## Technologies Used
- Python
- Cryptography Library


## How to Run

```bash
python main.py
